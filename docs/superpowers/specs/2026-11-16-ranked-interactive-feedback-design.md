# Ranked Mode Interactive Feedback Design (Visual Glow & Synthesized Audio)

**Date:** 2026-11-16  
**Status:** Approved by Owner  
**Target Branch:** `codex/ranked-mode`  
**Reference Mockup:** `mockups/design-library/quiz-feedback-demo.html`

---

## 1. Goal & Overview

Provide immediate, engaging, and accessible visual and auditory feedback when a player answers a question during a Ranked quiz attempt.

- **Visual Feedback:** 
  - Correct answer: Green glow (`#226442`), expansion pulse (`scale(1.04)`), and avatar cheer reaction.
  - Incorrect answer: Red glow (`#a12d2d`), subtle horizontal shake animation, and avatar oops reaction.
- **Audio Feedback:**
  - Fast, zero-latency synthesized sound effects via native `Web Audio API` (no extra asset requests, no external audio downloads).
  - Optional background focus music (BGM) loop with a clean mute/toggle control.
- **Accessibility & Preferences:**
  - Full conformance with `prefers-reduced-motion` (turns off shake and scaling; uses solid outline/contrast).
  - Explicit mute state persisted in `localStorage`.

---

## 2. Architecture & Components

### 2.1 Audio Synthesis Engine (`src/sound.js`)
A lightweight, self-contained module utilizing `window.AudioContext`:
- `playCorrectSfx()`: 4-note ascending major arpeggio (C5, E5, G5, C6) with sine wave and gentle exponential decay.
- `playIncorrectSfx()`: 2-tone soft buzzer (A3, F3) using triangle oscillator to avoid harshness.
- `playBgm()` / `stopBgm()`: Low-volume lo-fi ambient melody for focus mode.
- `toggleSound(enabled)` / `isSoundEnabled()`: State management respecting user mute toggle.

### 2.2 Quiz View Controller Integration (`src/quiz.js` & CSS)
- **CSS Animations:**
  - `@keyframes beltCorrectGlow`: Expanding green shadow pulse.
  - `@keyframes beltIncorrectShake`: Horizontal oscillation with red box-shadow.
  - `@media (prefers-reduced-motion: reduce)`: Overrides keyframe animations with static 4px borders.
- **Answer Selection Flow:**
  - On belt button click: Immediately apply `.belt-correct` or `.belt-incorrect`.
  - Trigger corresponding SFX (`playCorrectSfx()` or `playIncorrectSfx()`).
  - Send message to avatar iframe (`postMessage({ type: 'quiz-avatar', state: isCorrect ? 'correct' : 'incorrect' })`).
  - Disable answer buttons to prevent double-clicks during the 600ms–800ms transition window.
  - Proceed to question review/advance.

---

## 3. Scope Boundaries & Constraints

1. **Security & Data Invariants:** No changes to backend scoring, server-side timing, database schemas, or token authentication.
2. **Deterministic Settlement:** Visual feedback occurs locally upon answer submission; final points settlement remains authoritative on the server.
3. **No External CDN/MP3s:** Zero external network dependencies. All sounds are procedurally generated by Web Audio API.
